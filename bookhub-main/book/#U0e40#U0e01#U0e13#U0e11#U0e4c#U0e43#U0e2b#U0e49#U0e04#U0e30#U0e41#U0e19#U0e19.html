ฉบับเก็บคะแนน — 10 คะแนน

เกณฑ์ให้คะแนน — ระบบจัดการหนังสือในห้องสมุด (ฉบับเก็บคะแนน)

เขียนส่วน backend (PHP) เองทั้งหมด — starter บอกเฉพาะสิ่งที่ต้องทำ ไม่มีโค้ดให้ลอก
รายการไฟล์ที่เกี่ยวข้องคะแนน
authN — ล็อกอินตรวจรหัสผ่านถูกต้อง + ออกจากระบบครบ 3 ขั้น login.php, logout.php2.0
authZ — แก้ไข/ลบได้เฉพาะข้อมูลของตัวเอง (ทั้ง UI และตรวจฝั่งเซิร์ฟเวอร์) index.php, edit.php, delete.php2.0
Create — เพิ่มข้อมูลใหม่ด้วย prepared statement ถูกต้อง create.php2.0
Read — แสดงรายการทั้งหมดพร้อมชื่อผู้เพิ่ม เรียงใหม่ไปเก่า index.php1.0
Update — แก้ไขข้อมูลเดิมได้ถูกต้อง (รวมกรณีไม่เปลี่ยนรูป) edit.php1.5
Delete — ลบข้อมูลได้ถูกต้อง delete.php1.0
Upload — ใช้ safe_upload() ตรวจสอบไฟล์รูปก่อนบันทึกเสมอ create.php, edit.php0.5
รวม10.0
หักคะแนนทันทีถ้าพบ: ต่อ string เข้า SQL ตรง ๆ แทนการใช้ prepared statement, ไม่เช็ค owner_id ก่อนแก้ไข/ลบ (ให้แก้ไขข้อมูลคนอื่นได้), หรือไม่ใช้ safe_upload() ตรวจไฟล์ก่อนบันทึก
